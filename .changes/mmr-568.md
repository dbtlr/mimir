### Fixed

- **Tasks preserve the main conversation when a distinct agent takes ownership** (MMR-568). Main harness and session identify the user conversation or workflow; optional worker harness and session identify a separate agent responsible for the whole task lifecycle. Helpers leave task identity alone. Queueing reserves the main identity, starting preserves it, explicit worker flags record handoffs, and holds, cancellation, and completion clear all live handles while retaining ownership history. CLI, MCP, query, overview, and console surfaces expose both identities; the Mimir skill and isolated evaluation scenarios teach and verify solo and delegated ownership.

### Added

- **Service JSON names the unit file `unit_file`** (MMR-397). `mimir service
  status` units and the `service install` `paths` object carry a new
  `unit_file` key. It holds a launchd plist path on macOS and a systemd unit
  path on Linux.

### Deprecated

- **The `plist` key in service JSON** (MMR-397). It now mirrors `unit_file`
  on every platform and will be removed in a later release. Scripts should read
  `unit_file` instead.

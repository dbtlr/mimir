### Changed

- **`mimir-host tokens` leads with the device and drops the empty revoked column** (MMR-596). Columns are now DEVICE, USER, LAST USED as an age (`19m ago`, or `never`), and PAIRED as a date. REVOKED appears only under `--all`. JSON output is unchanged.

### Fixed

- **`mimir-host tokens` and `pending` fit the terminal** (MMR-596). Columns align by terminal cell, so wide-character device names no longer push a row out of line. A terminal too narrow for the columns prints one `LABEL value` block per row.

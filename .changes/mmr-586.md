### Security

- **Pairing refuses invisible and bidi characters in device names** (MMR-586). A pairing request whose device name holds a zero-width, bidi-override, or other non-printing character (format, private-use, unassigned, or line-separator) is now refused with the existing device-name error. Such a name used to look identical to an already paired device on `/pair` and in `mimir-host pending`, so approving it raised no "already paired" warning and minted a second token.

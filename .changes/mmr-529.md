### Added

- **Container host integration slice** (MMR-529). The console runs as a TanStack Start SPA on Bun with a local SQLite store and the existing `/api` contract. A root Dockerfile builds the host runtime.

### Changed

- **Shared console build and API dispatch** (MMR-529). The host and `mimir serve` share the transitional API dispatcher. The compiled binary embeds Start's prerendered shell and final PWA assets, preserving the existing `serve` workflow.

### Added

- **Projects report their latest activity** (MMR-494). Every project read and the project list carry `last_activity_at`: the newest instant across the project's own row, tasks, transitions, annotations, seeds, and artifacts, falling back to the project's `updated_at` when it has no children. It rides HTTP, MCP, and the CLI `json`, `jsonl`, and `records` output; the console will use it to order the project switcher.

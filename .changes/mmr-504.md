### Added

- **The review report carries cross-project work rows** (MMR-504). `GET /api/review` adds `now`, `shipped`, `runnable`, and `going_cold` across every active project, built by the work page's own rules and order and each row tagged with its `project` key. Each project in `projects` adds `live` (open tasks) and `going_cold` counts, and the list is now ordered pinned first, then by latest activity. `shipped` needs the caller's `?tz=` and is empty without it.

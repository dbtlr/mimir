### Added

- **Clients request pairing and the host approves it** (MMR-584). `POST /auth/pairing/requests` files a pairing request for a named device and returns a display code and a private poll secret. The operator approves or denies the code on the host, and `POST /auth/pairing/poll` collects the device token once. New requests are limited host-wide to ten in a rolling ten minutes. See [ADR 0038](docs/decisions/0038-device-pairing-and-the-version-window.md).

### Changed

- **Store schema 10 replaces pairing codes with pairing requests** (MMR-584). Migration 0010 drops `pairing_codes` and adds `pairing_requests`. Device tokens are unchanged, and a code pending at upgrade is discarded.

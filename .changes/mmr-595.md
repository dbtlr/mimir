### Changed

- **`json` and `jsonl` print through Loom's own views** (MMR-595). The Loom CLI and `mimir-host` hand Loom the data each format prints rather than pre-serialized text, so encoding and control escaping are Loom's. Output bytes stay as they were, including the one empty line an empty `jsonl` list prints and the one-line `json` documents of scratchpad, bind, notice, and store commands. `store export -` prints the transfer document exactly as the file holds it under every format.

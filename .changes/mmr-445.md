### Changed

- **Console renders descriptions, notes, and seed bodies as markdown** (MMR-445). Node descriptions, annotations, seed bodies, and the quick-view preview now show lists, code, links, and emphasis the same way artifacts and direction do, instead of raw markdown text. Rendered markdown also gets a heading hierarchy and theme-aware lists, quotes, and rules, with full-width scrolling tables, in both light and dark. Inline code is now coloured monospace text (a new code colour) instead of a dark pill, while fenced code blocks keep the dark well.

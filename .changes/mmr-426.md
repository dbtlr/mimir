### Security

- **`mimir serve` grants CORS to no origin** (MMR-426). It used to grant
  cross-origin access to any `localhost` or `127.0.0.1` page on any port, so
  another web app running on the same machine could read and write the board
  through the API. The console's dev loop now reaches the API through the
  `vite dev` proxy instead: run `mimir serve` from source and `bun run dev:ui`,
  and set `MIMIR_PORT` for both when `serve` uses a port other than its dev
  default. `VITE_API_BASE` is gone.

### Changed

- **The console's browsers, seed and artifact pages, and record health read the Engine** (MMR-540). The task, seed, and artifact browsers, the seed and artifact pages, the seed writes, and the record-health panel now run on the host's server functions instead of `/api`. A seed's page finds the tasks that name it as upstream on every board through the new `console.upstreamTasks` Engine method, which the CLI and MCP do not expose.
- **The dependency picker searches like the jump palette** (MMR-540). It finds open tasks on every board by id, title, or description, using the palette's search. A task that is not in flight shows a hollow status dot, since search cannot say whether open work is ready, blocked, or awaiting.

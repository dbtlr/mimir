- **A resume import accepts prose and remotes in any spelling** (MMR-609). A transfer document whose `## Next` text or task description had leading or trailing whitespace, or whose project remote was not in its stored form (such as `git@github.com:org/repo.git`), imported fresh, then refused to resume onto that same import with "already exists and differs from the transfer document". A resume now compares those fields as the target stores them, so a document always resumes onto its own fresh import. A present `## Next` with blank text still counts as present, and prose that truly differs is still refused. A store holding a project remote with a space in its path, such as `github.com/org/my repo`, can also now import its own export, where before it refused with "not a Git remote".

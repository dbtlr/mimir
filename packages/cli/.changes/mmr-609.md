- **A resume import accepts prose with stray whitespace** (MMR-609). A transfer document whose `## Next` text or task description had leading or trailing whitespace imported fresh, then refused to resume onto that same import with "already exists and differs from the transfer document". A resume now compares that prose as the target reads it back, trimmed and blank as none, so a document always resumes onto its own fresh import. A present `## Next` with blank text still counts as present.

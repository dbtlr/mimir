- **Keep the reset's reload from failing when another browser's kind saves meanwhile** (MMR-759). On Settings › Notifications, saving what another browser notifies about in the moment right after a push key reset could cancel the page's reload of the device list. The page then said "The push key was reset, but this page couldn't reload" and left this browser to heal on its next load. It now reads the list again, and this browser heals at once.

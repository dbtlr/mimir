- **The host image carries git, and the host can sync project clones** (MMR-631). The host keeps one clone per project at `clones/<KEY>` in `MIMIR_DATA_DIR`, fetched from `https://<remote>.git`, and syncs it to the remote's default branch before agent runs, refusing a clone with a symlink that leads outside it. `MIMIR_DATA_DIR` is now the host's working directory for every backend, not only SQLite's; a Postgres host still writes nothing there until a clone is needed. The new optional `MIMIR_GIT_CREDENTIALS_FILE` names a git credential-store file for private repositories, each credential sent only to its own repository and never copied into a clone, a URL, or the log. A missing or unreadable file logs a warning at startup and leaves public repositories working; only a private repository's sync fails, naming the setting. See [Clone private repositories](../../docs/guides/host.md#clone-private-repositories).

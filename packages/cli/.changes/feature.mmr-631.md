- Add `git` to the host image, and add the optional `MIMIR_GIT_CREDENTIALS_FILE` setting, which names a git credential-store file for cloning private project repositories. You can set it now: at startup the host checks the file and, when it is missing or unreadable, logs a warning that names the setting and keeps running. The host also gains the clone sync that agent runs will use, which keeps one clone per project at `clones/<KEY>` in `MIMIR_DATA_DIR`, fetched over HTTPS from the project's remote; it creates no clones until agent runs ship. Each credential is sent only to its own repository and is never copied into a clone, a URL, or the log. See [Clone private repositories](../../docs/guides/host.md#clone-private-repositories).
- Change `MIMIR_DATA_DIR` to be the host's working directory for every backend, not only SQLite's. A Postgres host still writes nothing there at startup.

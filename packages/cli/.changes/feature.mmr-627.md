- **`queue` and `start` record the T3 host inside a T3 thread** (MMR-627). When the main identity recorded is the shell's T3 thread and `T3CODE_ENVIRONMENT_ID` is nonblank, an omitted `--host` fills with that environment id, so a task an agent queues or starts by hand gets the console's Open in T3 link. This applies whether the shell filled the harness and session or the agent passed them. A passed `--host` wins, another harness or session fills no host, and without the variable no host is recorded. The skill tells agents in T3 to pass `--host "$T3CODE_ENVIRONMENT_ID"` when it is set.

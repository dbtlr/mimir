- **The host console connects to T3 Code** (MMR-624). Set `MIMIR_T3_URL` to a T3 Code server's origin and the Devices page shows a T3 Code card: **Connect T3** signs in on T3's own screen, and the card reports the connection's server and expiry, an expired or refused connection with **Reconnect T3**, an unreachable T3, or the setting that is missing. The connection's token is stored encrypted under a new secret key, `MIMIR_SECRET_KEY` or `MIMIR_SECRET_KEY_FILE`, which never enters the store; setting both refuses startup. The integration also needs `MIMIR_HOSTS` and, unless the console is used only on loopback, an HTTPS `MIMIR_URL`. A problem with any of these logs a warning at startup and keeps the integration off without stopping the host. Without `MIMIR_T3_URL`, nothing changes.
- **Schema version 12 stores host secrets** (MMR-624). The host applies the migration at startup; rolling the host image back past it needs a database restore. Export and import skip the new table, so a board transfer never carries a credential.

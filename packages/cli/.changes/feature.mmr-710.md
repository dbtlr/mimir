- **Show each Web Push in the installed console and open its record on a tap** (MMR-710). The console's service worker shows every push the host sends with its title, body, and tag, and alerts again for a push whose tag repeats. A push it cannot read still shows a generic notification, so no push arrives silently. A tap brings an open console window to the record and focuses it, or opens the console at the record; it follows only addresses on the console's own origin. The app icon's badge shows the needs-you count, set by each push and kept current by the open console. On an iPhone the browser shows and opens the declarative push itself, without the service worker.

- **A remote with a bracketed host is now refused** (MMR-613). A scp-style remote with an IPv6 host, such as `git@[::1]:o/r`, was cut at the first `:` inside the brackets and stored as `[/:1]:o/r`, which is not the repository's identity, so two such remotes on one host could collide or fail to bind. Any remote whose host is in brackets, in the scp form or a URL such as `https://[::1]/o/r`, is now refused as "not a Git remote" when it is set, as the URL form with a port already was. A store that already holds a remote in the garbled form keeps it, and its export still imports; replace it with `mimir update KEY --remote <url>`, or clear it with a blank `--remote ""`.

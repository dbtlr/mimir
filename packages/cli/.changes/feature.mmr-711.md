- **Turn on Web Push notifications from the console** (MMR-711). Settings has a new Notifications page, first in "This device", where a browser turns notifications on or off, sends itself a test, and sees every subscribed browser: each other browser's row offers Send test notification and Remove, and a row made for an old key offers only Remove. A browser's label is generated, such as `Mac · Chrome` or `iPhone · Home Screen app`. Each state says what to do next: set up the host, add the console to the Home Screen on an iPhone, or undo a blocked permission. When the console opens, it subscribes a browser again after the host resets its push key, or after the browser drops or replaces its subscription, and leaves a browser that another device removed off. Reset push key asks first, and is the one action when the host cannot open its key.

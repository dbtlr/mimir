- **Say each sidebar row's status in words, not only by its dot's colour** (MMR-807). A screen reader now hears the status of every project, initiative, and phase row in the console sidebar, for example "initiative MMR-1 0/3, Ready", where before a ready initiative and a blocked one read the same. Home's row, which draws no dot, is unchanged. A project row with nothing needing you no longer carries a stray space before the status.

- **Build on Loom 0.20.0** (MMR-746). Words after `--` still reach a title, note, reason, or tag that leads with a dash, as in `mimir park MMR-3 -- -1 day`. A word after `--` that no argument takes now fails with Loom's message, such as `Command "start" accepts 1 argument.`, with code `unexpected-argument` and exit 2. Before, it failed with `unexpected argument: <word>` and code `usage`. `item check MMR-3 -- -1` now reads `-1` as the item number and refuses it as not positive. Help lists Loom's `--fields` option on every command with `--format`. Mimir's own `json` and `jsonl` views refuse it with exit 2, and the MCP tools do not take it. `install.sh` gains `--unmanaged`, which installs a side copy into `--dir` with no installation record, PATH advice, or post-install command.
- **Bump the minor for a feature, not only for a breaking change** (MMR-746). Below 1.0, a release with a new feature is now a minor release, and a patch release holds only fixes, so the next release is 0.31.0. See [ADR 0047](../../docs/decisions/0047-below-1-0-a-feature-advances-the-minor.md).

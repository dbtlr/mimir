- **A project remote that could not be stored is now refused, and a stray space before a stripped suffix is dropped** (MMR-612). A remote whose host held `@`, `?`, `#`, or a backslash, such as `https://a@b@c.com/x` or `git@a?b.com:x`, was accepted and stored, then refused as "not a Git remote" when the store imported its own export. Such a remote is now refused as not a Git remote when it is set. A trailing space before a stripped `/` or `.git`, as in `https://github.com/org/repo /`, is also dropped, so every stored remote imports from its own export. A store that already holds such a remote keeps it; correct it with `mimir update KEY --remote <url>`.

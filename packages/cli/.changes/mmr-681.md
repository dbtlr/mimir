- **Refuse a bad `block --on` value as a usage error** (MMR-681). `mimir block KEY-9 --on me` now exits 2 with code `usage` before it opens the store, as every other enum flag does, instead of exiting 1 with a `validation` error. The message and hint are unchanged: `invalid on: me`, `block on takes one of: you, others`. The skill drift check now catches a bad `--on` value in a skill file.

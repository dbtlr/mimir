- **Body text in the console keeps one line height** (MMR-749). Every paragraph of body text now draws with the same 23px line, as the console's design guide sets, where most drew at 21px and only a few states reached 23. Labels that are not prose, such as a button's label, the project picker's name, the notification switches, and the needs-you count on a phone, take the tighter 20px label line, so the project picker's row in the desktop sidebar is 1px shorter.

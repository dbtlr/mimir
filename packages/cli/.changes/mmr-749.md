- **Body text in the console keeps one line height** (MMR-749). Every paragraph of body text now draws with the same 23px line, as the console's design guide sets, where most drew at 21px and only a few states reached 23. Labels that are not prose take the tighter 20px label line: a button's label, the project picker's name, the notification switches, and the needs-you count on a phone. So a default button is 32px tall wherever it sits, and the project picker's row in the desktop sidebar and a Settings › Notifications row are each 1px shorter.

- **The installer registers Mimir with Codex** (MMR-604). After it installs the binary, `install.sh` now runs `mimir mcp install` without `--agent`, so it registers the MCP server with Claude Code and Codex, skipping either one that is not installed. The server now speaks the protocol revision Codex opens with, so Codex lists and calls Mimir's tools. An installation from before this release registered Claude Code alone: run `mimir mcp install --agent codex` once to add Codex. See [Install location](../../docs/guides/install-location.md).

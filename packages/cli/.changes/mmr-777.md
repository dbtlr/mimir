- **A disabled field keeps its value readable** (MMR-777). The console's shared field controls (text box, text area, tag input, menu, and record picker) now show their value in full-strength secondary ink when disabled, and only the edge and chevron step down, as a disabled commit button already does. A disabled field that is invalid keeps its red edge. Before, the whole field faded to 40% or 50%, and a disabled menu's value measured about 2.4:1 in the light theme. Checkboxes, radios, switches, and outline buttons still fade.

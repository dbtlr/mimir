- **Stop a running agent run from the console** (MMR-635). The running Groom with agent card has a **Stop** button in its header, and the work page's Now row has a stop icon. Each opens a confirm that names the task and opens on **Keep running**. A stopped run finishes the step it is on and then stops, usually within seconds. The card reads **Stopping the agent** until the run closes, and then **You stopped this run**, with the tokens the run used. A stopped run is charged what it really used, not its reservation. If it has not stopped after 5 minutes, the host aborts it, and it counts its reservation or its streamed usage, whichever is larger. A run stopped before it reached the agent is charged nothing. Notes the agent already wrote stay on the task. A run that another host is running, or whose host stopped reporting, cannot be stopped from here, and the confirm says why. See [Set up agent runs](../../docs/guides/host.md#set-up-agent-runs).

- Add Claude Code to the host image (MMR-632). The image installs the Claude Code 2.1.318 executable for amd64 and arm64, checked against its published checksum, and sets `MIMIR_AGENT_CLAUDE_PATH` to it. A `MIMIR_AGENT_CLAUDE_PATH` that is not an executable file turns agent runs off with a warning that names the setting.
- Add agent-run setup to the host (MMR-632). Set `MIMIR_AGENT_TOKEN_FILE` to a file holding a `claude setup-token` token to turn on agent runs. With it, `MIMIR_HOSTS` and a writable `MIMIR_DATA_DIR` are required. A missing or empty token file or a missing prerequisite logs a warning that names the setting and keeps the host running. The console cannot start a run yet. See [Set up agent runs](../../docs/guides/host.md#set-up-agent-runs).
- Add the agent-run tuning settings (MMR-632). `MIMIR_AGENT_DAILY_TOKENS`, `MIMIR_AGENT_RUN_TOKENS`, `MIMIR_AGENT_MAX_TURNS`, `MIMIR_AGENT_BUDGET_TIMEZONE`, and `MIMIR_AGENT_MODEL` set the daily token budget, a run's ceiling, its turns, the budget day's time zone, and the model. A bad value, a UTC offset as the time zone included, warns and falls back to its default.
- Add the agent runner and its daily token budget to the host (MMR-632). The host runs one agent run at a time against a `todo` task in a project with a remote, after it syncs the project's clone. Each run reserves `MIMIR_AGENT_RUN_TOKENS`, and the host refuses a run when the day's usage plus that reservation exceeds `MIMIR_AGENT_DAILY_TOKENS`; the refusal names when the budget day resets. A run counts the tokens it processed on every model, is stopped when its estimate reaches its reservation, and leaves no transcript. The console cannot start a run yet. See [Know what the token budget counts](../../docs/guides/host.md#know-what-the-token-budget-counts).

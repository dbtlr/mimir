- **The host image carries Claude Code, and agent runs can be set up** (MMR-632). The image now installs the Claude Code 2.1.318 executable for amd64 and arm64, checked against its published checksum, and sets `MIMIR_AGENT_CLAUDE_PATH` to it. Set `MIMIR_AGENT_TOKEN_FILE` to a file holding a `claude setup-token` token to turn on agent runs; with it, `MIMIR_HOSTS` and a writable `MIMIR_DATA_DIR` are required, and a missing or empty token file or a missing prerequisite logs a warning that names the setting and keeps the host running. `MIMIR_AGENT_DAILY_TOKENS`, `MIMIR_AGENT_RUN_TOKENS`, `MIMIR_AGENT_MAX_TURNS`, `MIMIR_AGENT_BUDGET_TIMEZONE`, and `MIMIR_AGENT_MODEL` tune the daily token budget, a run's ceiling, its turns, the budget day's time zone, and the model; a bad value warns and falls back to its default. The console cannot start a run yet. See [Set up agent runs](../../docs/guides/host.md#set-up-agent-runs).

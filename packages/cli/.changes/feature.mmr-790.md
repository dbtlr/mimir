- **The Projects page lists every project, the ones that need you first** (MMR-790). The console has a page at `/projects` with a row for each active project, ordered by how many items need you, then by how much work is live, then by name. On a phone a row shows one count: "2 need you" in the violet pill, else "36 live", else "Nothing live" with the name dimmed. On desktop a row shows five columns: _Need you_, _To triage_, _In flight_, _Live_, and _Going cold_, with a dash for zero. Archived projects sit in a closed _Archived_ fold after the list, and _New project_ sits beside the title. Every row opens the project's page. On every page outside a project, the sidebar's _Projects_ section ends in _See all N projects_, which opens the page.

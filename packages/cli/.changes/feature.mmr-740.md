- **Ask through one confirm dialog for Unpair, Deny, and the push key reset** (MMR-740). On Settings › Devices, _Unpair_ now opens a centred confirm dialog instead of swapping in place, and on _Pair a device_, _Deny_ asks before it discards the request. Resetting the push key opens the same dialog instead of a bottom sheet. Each opens on _Cancel_ and ignores a press outside. While the call runs, _Stop run_, _Unpair_, the push key reset, _Deny_, and the answer to a question hold the dialog open: _Cancel_ is disabled, Escape does nothing, and a second press sends nothing. The answer to a question is saved without its leading and trailing spaces. _Cancel_ or Escape returns focus to the button that opened the dialog, also when several buttons open the same one. Stopping an agent run, and every action that takes a reason (park, block, abandon, return, reject, resolve, pause or abandon a delivery, answer a question, and a decision's note), share the same two dialogs.

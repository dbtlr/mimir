- **Ask through one confirm dialog for Unpair, Deny, and the push key reset** (MMR-740). On Settings › Devices, _Unpair_ now opens a centred confirm dialog instead of swapping in place, and on _Pair a device_, _Deny_ asks before it discards the request. Resetting the push key opens the same dialog instead of a bottom sheet. Each opens on _Cancel_, ignores a press outside, and returns focus to the button that opened it. Stopping an agent run, and every action that takes a reason (park, block, abandon, return, reject, resolve, pause or abandon a delivery, answer a question, and a decision's note), share the same two dialogs.

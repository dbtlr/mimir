- **Install a side copy with `install.sh --unmanaged`** (MMR-746). `install.sh --unmanaged --dir <directory>` installs the binary into that directory with no installation record, no PATH advice, and no post-install command. A side copy has no receipt, so it runs on development directories, not your board. `--unmanaged` needs `--dir`.
- **Release a feature as a minor version** (MMR-746). Below 1.0, a release with a new feature now bumps the minor, as a breaking change does, and a patch release holds only fixes. A CLI on a newer minor than its host is outside the version window, so update the host before its CLIs after a feature release. See [ADR 0047](../../docs/decisions/0047-below-1-0-a-feature-advances-the-minor.md).

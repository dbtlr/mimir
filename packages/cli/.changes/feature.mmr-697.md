- **Every `mimir mcp` tool declares whether it reads and whether it deletes** (MMR-697). Each tool in `tools/list` now sets both `readOnlyHint` and `destructiveHint`, so an MCP client or proxy that filters on either hint alone sees an explicit value. The 14 read tools now also say `destructiveHint: false`; before, they left it out, and a client that checks it without `readOnlyHint` took MCP's default of true. Only `scratch_discard`, which deletes a scratchpad and its content, is destructive. `undepend` and `untag` are no longer destructive: they remove an edge that another call restores, as `update` and `scratch_update` do. `scratch_freeze` stays non-destructive because the scratchpad's content is kept as an artifact.

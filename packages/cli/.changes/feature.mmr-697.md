- **Every `mimir mcp` tool declares whether it reads and whether it deletes** (MMR-697). Each tool in `tools/list` now sets both `readOnlyHint` and `destructiveHint`, so an MCP client or a proxy that filters by these hints classifies every tool correctly. The 14 read tools now say `destructiveHint: false`, where before they left it out and MCP's default read them as destructive. Only `scratch_discard`, which deletes a scratchpad, is destructive. `undepend` and `untag` are no longer destructive: they remove an edge that another call restores, as `update` and `scratch_update` do.

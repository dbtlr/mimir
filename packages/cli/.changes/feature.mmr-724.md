- **The Tasks list has presets, a Filter sheet, and doors from Home** (MMR-724). A project's Tasks tab opens with a count line, a search field, and a chip for the active preset. There are four presets: _In flight_, _Ready_, _Going cold_, and _Shipped, last 7 days_. Each preset is a `show` value in the URL, so a link can open it, and removing its chip shows every live task. _Filter_ opens a sheet with Show, Status, Priority, Size, Tag, and Sort, and nothing changes until its button, which names the result ("Show 5 tasks"), is pressed. Live tasks are cards grouped by status, and a group's heading stays in view while the group scrolls. Shipped tasks are rows folded by day, with only the latest day open. On Home, each project's row in _Shipped this week_ opens that project's _Shipped, last 7 days_, and _Now_, _Ready to start_, and _Going cold_ gain _See all_ when everything in them belongs to one project. Existing `?status=` and `?q=` links still work.

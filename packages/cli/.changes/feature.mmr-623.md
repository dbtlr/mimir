- **`queue` and `start` record the T3 thread they run in** (MMR-623). When the shell carries a nonblank `T3CODE_THREAD_ID`, an omitted main harness and session fill as `t3` and that thread id, so the task points at the T3 thread you resume rather than the agent session T3 wraps. T3 wins over every agent detected under it, including nested agents that otherwise fill nothing and report multiple harnesses. Passed flags keep their existing rule: `--harness claude` inside T3 records no session. T3 0.1.6 sets the variable only for its Claude threads, so a Codex thread in T3 still records `codex` and its own thread id.

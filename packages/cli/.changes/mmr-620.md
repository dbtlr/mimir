- **The going-cold chip no longer reads as in progress** (MMR-620). The console's `⧗ stale` chip, on work-page rows, rows in _Needs you_, and a task page's signals, used the in-progress amber, so a stale ready, queued, or blocked task looked like work in flight. It now draws as a neutral chip with secondary text, like the size chip beside it, in both themes, and its tooltip reads "untouched in a while" instead of "in flight too long".

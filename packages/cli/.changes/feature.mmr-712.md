- **Choose which kinds of needs-you records notify each browser** (MMR-712). On Settings › Notifications, a browser that is on gets a "Notify this device about" group with a switch for each kind: stopped deliveries, decisions to confirm, tasks blocked on you, and tasks that need answers. Another subscribed browser's row offers "Choose what notifies…" while it is on the current push key (a row on an old key does not), which opens the same switches in a sheet on a phone or a dialog on a desktop. A switch saves the moment it flips, and the host then sends that browser no push of a muted kind. Every kind is on by default, turning every kind off is allowed, and a test notification still goes through. A browser keeps its choice when it subscribes again after a push key reset or a new endpoint, and starts with every kind on after Turn off and Turn on. The badge still counts everything that needs you. The host's store moves to schema 24, so update the host before its paired CLIs, as with every schema step.

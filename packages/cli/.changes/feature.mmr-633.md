- **Groom a task with an agent from the console** (MMR-633). With agent runs set up, a `todo` task's page shows a **Groom with agent** card above its description. One click starts an agent on the host that reads the task and the project's code, writes its findings as notes with evidence, and sets the task's grooming: groomed, or needs answers with each question and a recommended answer. It never changes a task's status or touches another task. The card shows the model, the day's token budget with the run's reservation, and the token file's age. While the run works, the card and the work page's Now show it with its token use. When a run cannot start, the card says why: the budget, with when it resets; another run, with its task; a refused token; a missing setting; a project with no remote; or Claude Code managed settings on the host. A run that fails, including a clone that does not sync, shows its outcome on the task. See [Set up agent runs](../../docs/guides/host.md#set-up-agent-runs).

- **Send Web Push notifications from the host** (MMR-709). Set `MIMIR_PUSH_CONTACT` to a `mailto:` or `https:` contact, with `MIMIR_URL`, `MIMIR_HOSTS`, and the secret key, and the host sends each needs-you event as an encrypted Web Push to every subscribed browser, and opening a notification opens its record. This is the host side: the console's control for subscribing a device comes in a later release. The host signs with a VAPID key sealed under the secret key, keeps at most 20 subscriptions, and accepts endpoints only on the Apple, Google, Mozilla, and Microsoft push services. A push service's 404 or 410 removes the subscription. A missing or wrong setting warns at startup by name and leaves the channel off. The store schema advances to 23 with a `push_subscriptions` table, which export and import skip. See [Turn on Web Push notifications](../../docs/guides/host.md#turn-on-web-push-notifications).

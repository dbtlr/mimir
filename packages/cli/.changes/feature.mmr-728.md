- **A task's page opens on Work, with Details, Timeline, and Artifacts a tab away** (MMR-728). The console's task page drops its right rail and its _Links_, _Agent_, and _Details_ chips and takes the one page column, with tabs as initiatives and phases have. _Work_ leads with a card for the task's state: _Agent at work_ while a run is live (the latest note, harness, branch, and _Open in T3_), _Submitted for review_ with the review summary and its pull request, or the hold with its reason (_Blocked on you_ in violet). The description follows, then what the task depends on and blocks. _Details_ holds _Status_, _Record_, and _Run_, and _Run_ keeps the sessions, branch, host, and external ref after the run ends. `?tab=details`, `timeline`, or `artifacts` opens a tab directly. A task blocked on you offers _Unblock_ as its main action.
- **Every record's timeline is newest first, folded by day** (MMR-728). On task, initiative, and phase pages, _Timeline_ starts with the note box (its button now reads _Add note_), then shows entries newest first under one fold per day, with only the latest day open. Notes are cards on a thread through the events. A note longer than 12 lines is cut at the twelfth line under _Show all N lines_.

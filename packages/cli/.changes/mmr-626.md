- **Priority and seed-kind chips no longer read as statuses** (MMR-626). In the console, a p0 priority chip and a `bug` seed used the blocked red, p1 and `idea` the in-progress amber, and `feature` the ready blue, so a p0 task looked blocked and an idea looked like work in flight. Priority chips now draw in neutral text that dims from p0 (brightest, bold) to p3, and every seed kind draws as the same neutral chip, in both themes. The selected priority and kind in the new-task sheet and the seed capture use the same neutral selection as the size picker.

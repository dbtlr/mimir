- **Return focus to the entry that opened the decisions walkthrough when it closes** (MMR-714). Closing a walkthrough that an entry opened, or following the done screen's link back to the page you came from, now puts keyboard focus on the entry you activated, on the review page or the delivery page, instead of losing it. An entry in the _Needs you_ popover or sheet returns focus to the _Needs you_ alert, because the popover is closed. When the entry is gone, because you answered the whole set, focus lands on the page's main region. See [ADR 0019's MMR-714 refinement](../../docs/decisions/0019-meridian-console-design-system.md).

- **Return focus to the entry that opened the decisions walkthrough when it closes** (MMR-714). Close, and the link back when it goes back, now put keyboard focus on the entry the operator activated, on the review page or the delivery page, instead of on the document. An entry in the _Needs you_ popover returns focus to the _Needs you_ button, because the popover is closed. When the entry is gone, because the whole set was answered, focus lands on the page's main region. See [ADR 0019's MMR-704 refinement](../../docs/decisions/0019-meridian-console-design-system.md).

- **Stop a host whose clock runs ahead from interrupting another host's live agent run** (MMR-698). Agent run heartbeats and the stale cutoff now read the database's clock instead of each host's own, so a second host during an overlapping deploy no longer marks the first host's live run interrupted or admits a second run beside it. The console's running-run status and Stop judge a stale run by the same clock, so a host whose clock is off no longer shows a live run as stopped reporting.

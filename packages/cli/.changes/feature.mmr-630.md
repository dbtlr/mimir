- **Schema version 13 stores the host's agent runs** (MMR-630). A SQLite store, a local CLI's included, migrates to schema 13 when it is opened, and the host's Postgres store migrates at host startup. Older binaries then refuse the store, so rolling back past this release needs a restore from a backup taken before the upgrade. The new `runs` table holds one record per agent run and allows only one running run at a time. Export and import skip the table, and no command or tool reads it yet.

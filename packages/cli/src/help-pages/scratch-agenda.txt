mimir scratch agenda · Change a scratchpad's agenda: add an item, complete one, or supersede one with a reason.

USAGE
  mimir scratch agenda <action> <id> [words...] [options]

ARGUMENTS
  action  add, complete, or supersede.
  id      The scratchpad UUID.
  words   For add, the item; for complete and supersede, the item number then any reason.

OPTIONS
      --expected-updated-at <timestamp>  The scratchpad's updated_at as last read: the write is refused if it changed since.
      --reason <text>                    For supersede, why, in place of the words after the number.
      --ascii                            Print without color, in ASCII glyphs.
  -f, --format <format>                  Select the output format, records by default. One of: ids, json, jsonl, records, table.

GLOBAL OPTIONS
  -h, --help  Show this help.

EXAMPLES
  $ mimir scratch agenda add <id> Port the verbs
    add an item
  $ mimir scratch agenda complete <id> 2
    mark item 2 done
  $ mimir scratch agenda supersede <id> 3 folded into 2
    with its reason

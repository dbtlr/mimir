mimir create · Create a project, initiative, phase, or task.

USAGE
  mimir create <command> [options]

COMMANDS
  project     Create a project. Its key is immutable, so creating one asks for confirmation.
  initiative  Create an initiative under a project.
  phase       Create a phase under an initiative.
  task        Create a task under a phase or initiative.

GLOBAL OPTIONS
  -h, --help      Show this help.
      --no-input  Ask no questions, and take every answer from options.  (default: true)

Run mimir create <command> --help for command details.

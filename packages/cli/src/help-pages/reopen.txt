mimir reopen · Reopen a terminal task (done/abandoned → in_progress).

USAGE
  mimir reopen <id> [reason...] [options]

ARGUMENTS
  id      The task: KEY-seq.
  reason  The reason is optional; it is recorded in the transition log.

OPTIONS
      --ascii            Print without color, in ASCII glyphs.
  -f, --format <format>  Select the output format, records by default. One of: ids, json, jsonl, records, table.

GLOBAL OPTIONS
  -h, --help      Show this help.
      --no-input  Ask no questions, and take every answer from options.  (default: true)

EXAMPLES
  $ mimir reopen MMR-3
    back to in_progress

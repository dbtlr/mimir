mimir return · Send back for changes (under_review/staged → in_progress). Also takes a delivery (KEY-dN); delivery reasons are required for block, park, and abandon; task handle flags and block --on are refused.

USAGE
  mimir return <id> [reason...] [options]

ARGUMENTS
  id      The task: KEY-seq.
  reason  The reason is optional; it is recorded in the transition log.

OPTIONS
      --ascii            Print without color, in ASCII glyphs.
  -f, --format <format>  Select the output format, records by default. One of: ids, json, jsonl, records, table.

GLOBAL OPTIONS
  -h, --help      Show this help.
      --no-input  Ask no questions, and take every answer from options.  (default: true)

EXAMPLES
  $ mimir return MMR-3 "needs tests"
    send it back with a reason

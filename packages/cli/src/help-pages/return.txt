mimir return · Send back for changes (under_review/staged → in_progress). Also takes a delivery (KEY-dN): milestone → running, with an optional reason.

USAGE
  mimir return <id> [reason...] [options]

ARGUMENTS
  id      The task (KEY-seq) or the delivery (KEY-dN).
  reason  For a task the reason is optional and recorded in the transition log; for a delivery it is optional and recorded in the delivery history.

OPTIONS
      --ascii            Print without color, in ASCII glyphs.
  -f, --format <format>  Select the output format, records by default. One of: ids, json, jsonl, records, table.
      --fields <fields>  Select top-level fields of json and jsonl output, as a comma list.  (repeatable)

GLOBAL OPTIONS
  -h, --help      Show this help.
      --no-input  Ask no questions, and take every answer from options.  (default: true)

EXAMPLES
  $ mimir return MMR-3 "needs tests"
    send it back with a reason

mimir get · Read one full record: a task, phase, or initiative (KEY-seq), a project (KEY), an artifact (KEY-aN), a seed (KEY-sN), a delivery (KEY-dN), or a decision (KEY-qN).

USAGE
  mimir get <id> [options]

ARGUMENTS
  id  KEY-seq, KEY, KEY-aN, KEY-sN, KEY-dN, or KEY-qN.

OPTIONS
      --col <col>        Add a column (deps tags children distribution …). Repeat it, or separate with commas.  (repeatable)
      --since <INSTANT>  A delivery's change feed: events after this zoned instant (KEY-dN only). Pass the answer's as_of next time.
      --ascii            Print without color, in ASCII glyphs.
  -f, --format <format>  Select the output format, records by default. One of: ids, json, jsonl, records, table.

GLOBAL OPTIONS
  -h, --help      Show this help.
      --no-input  Ask no questions, and take every answer from options.  (default: true)

EXAMPLES
  $ mimir get MMR-16
    the full record, cheap facets included
  $ mimir get MMR-16 --col history
    add the transition log
  $ mimir get MMR-16 --col annotations
    expand annotation bodies
  $ mimir get MMR-a1 --col content
    an artifact's frozen body
  $ mimir get MMR-s1
    a seed, with its description
  $ mimir get MMR-d1
    a delivery, with its history
  $ mimir get MMR-d1 --since 2026-11-16T09:00:00Z
    a delivery's changes after that instant, with the cursor for the next read

mimir abandon · Abandon a task (kept, not deleted). Also takes a delivery (KEY-dN): agreed/running/milestone → abandoned, with a required reason.

USAGE
  mimir abandon <id> [reason...] [options]

ARGUMENTS
  id      The task (KEY-seq) or the delivery (KEY-dN).
  reason  For a task the reason is optional and recorded in the transition log; for a delivery it is required and recorded in the delivery history.

OPTIONS
      --ascii            Print without color, in ASCII glyphs.
  -f, --format <format>  Select the output format, records by default. One of: ids, json, jsonl, records, table.
      --fields <fields>  Select top-level fields of json and jsonl output, as a comma list.  (repeatable)

GLOBAL OPTIONS
  -h, --help      Show this help.
      --no-input  Ask no questions, and take every answer from options.  (default: true)

EXAMPLES
  $ mimir abandon MMR-3 "superseded by MMR-9"
    kept, not deleted

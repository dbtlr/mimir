mimir projects · List the projects, key-ordered. The clone binding never narrows this read.

USAGE
  mimir projects [options]

OPTIONS
      --status <shelf>   The shelf: active (the default), archived, or all.
      --ascii            Print without color, in ASCII glyphs.
  -f, --format <format>  Select the output format, table by default. One of: ids, json, jsonl, records, table.

GLOBAL OPTIONS
  -h, --help  Show this help.

EXAMPLES
  $ mimir projects
    every active project
  $ mimir projects --status archived
    the archived shelf
  $ mimir projects --status all -f ids
    every key taken, archived included
  $ mimir projects -f json
    structured output for scripts

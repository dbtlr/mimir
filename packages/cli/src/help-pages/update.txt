mimir update · Change a task, phase, or initiative (KEY-seq), a project (KEY), an artifact (KEY-aN), or a seed (KEY-sN).

USAGE
  mimir update <id> [options]

ARGUMENTS
  id  KEY-seq, KEY, KEY-aN, or KEY-sN.

OPTIONS
      --title <text>            The new title.
      --desc <text>             The new description.
      --direction <text>        A container's ## Next narrative.
      --summary <text>          A one-line summary.
  -p, --priority <p0..p3>       p0, p1, p2, or p3.
      --size <s|m|l>            s, m, or l.
      --target <date>           A phase's target, such as 2026-11.
      --ref <ref>               A task's external reference.
      --upstream <KEY-sN|none>  A task's seed on another board, or none to clear.
      --host <text>             Resume handle: the host working on it.
      --harness <text>          Main conversation: the agent harness.
      --session <text>          Main conversation: the session id.
      --worker-harness <text>   Whole-task worker: the agent harness.
      --worker-session <text>   Whole-task worker: the session id.
      --branch <text>           Resume handle: the Git branch.
      --open-ended              Mark a phase or initiative open-ended.
      --not-open-ended          Mark it not open-ended.
      --name <text>             A project's new name.
      --pinned                  Pin a project.
      --not-pinned              Unpin a project.
      --remote <url>            A project's Git remote; blank clears it.
  -k, --kind <kind>             A seed's kind: idea, bug, feature.
      --ascii                   Print without color, in ASCII glyphs.
  -f, --format <format>         Select the output format, records by default. One of: ids, json, jsonl, records, table.

GLOBAL OPTIONS
  -h, --help      Show this help.
      --no-input  Ask no questions, and take every answer from options.  (default: true)

EXAMPLES
  $ mimir update MMR-16 --title "Wire the store once"
    retitle a task
  $ mimir update MMR-16 -p p1 --size m
    priority and size
  $ mimir update MMR-4 --direction "Next: …"
    a container's ## Next narrative
  $ mimir update MMR --pinned
    pin a project
  $ mimir update MMR-a1 --title "…"
    retitle an artifact
  $ mimir update MMR-s1 --kind bug
    change a seed's kind
  $ mimir update MMR --remote git@github.com:dbtlr/mimir.git
    a project's remote

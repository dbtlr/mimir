mimir unqueue · Cancel a reservation and return the task to todo (queued → todo).

USAGE
  mimir unqueue <id> [reason...] [options]

ARGUMENTS
  id      The task: KEY-seq.
  reason  The reason is required; it is recorded in the transition log.

OPTIONS
      --ascii            Print without color, in ASCII glyphs.
  -f, --format <format>  Select the output format, records by default. One of: ids, json, jsonl, records, table.

GLOBAL OPTIONS
  -h, --help  Show this help.

EXAMPLES
  $ mimir unqueue MMR-3 "run cancelled"
    release the reservation

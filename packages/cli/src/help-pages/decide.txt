mimir decide · Record a provisional answer without stopping work.

USAGE
  mimir decide <question> --recommend <n> --class <text> [options]

ARGUMENTS
  question  The question answered.

OPTIONS
      --option <text>    An option; repeat at least twice.  (repeatable)
      --detail <text>    Option context as N: text; repeat.  (repeatable)
      --recommend <n>    The recommended option number.  (required)
      --take <n>         The option taken; defaults to recommend.
      --class <text>     product, architecture, or other.  (required)
      --why <text>       The rationale.
      --delivery <text>  The nonterminal delivery (KEY-dN).
      --task <text>      A task built on this answer; repeat.  (repeatable)
  -p, --project <text>   The project; defaults to the clone binding.
      --ascii            Print without color, in ASCII glyphs.
  -f, --format <format>  Select the output format, records by default. One of: ids, json, jsonl, records, table.

GLOBAL OPTIONS
  -h, --help      Show this help.
      --no-input  Ask no questions, and take every answer from options.  (default: true)

EXAMPLES
  $ mimir decide "Where?" --option Here --option There --recommend 1 --class product -p MMR
    take an answer

mimir start · Begin a task (todo/queued → in_progress).

USAGE
  mimir start <id> [options]

ARGUMENTS
  id  The task: KEY-seq.

OPTIONS
      --host <text>            The machine the work is happening on.
      --harness <text>         The main conversation or workflow harness.
      --session <text>         The main conversation or workflow session.
      --branch <text>          The branch the work lives on.
      --worker-harness <text>  The distinct whole-task worker harness, when known.
      --worker-session <text>  The distinct whole-task worker session; requires a main session.
      --ascii                  Print without color, in ASCII glyphs.
  -f, --format <format>        Select the output format, records by default. One of: ids, json, jsonl, records, table.

GLOBAL OPTIONS
  -h, --help      Show this help.
      --no-input  Ask no questions, and take every answer from options.  (default: true)

EXAMPLES
  $ mimir start MMR-3
    begin the task
  $ mimir start MMR-3 --host laptop --harness codex --session s-91 --branch feat/mmr-3
    work in the main conversation
  $ mimir start MMR-3 --worker-session worker-92 --worker-harness claude
    hand the whole task to a distinct worker
  $ mimir update MMR-3 --worker-session worker-93
    worker takeover; omitted harness becomes unknown

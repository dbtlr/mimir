mimir · Query and manage work state.

USAGE
  mimir <command> [options]

COMMANDS
  get                Read one full record: a task, phase, or initiative (KEY-seq), a project (KEY), an artifact (KEY-aN), or a seed (KEY-sN).
  next               List the ready tasks of one project in rank order.
  list               Select the nodes of one project by predicate, status, or tag.
  projects           List the projects, key-ordered. The clone binding never narrows this read.
  status             Read the rollup status and distribution of a node (KEY-seq) or project (KEY).
  tree               Read the full subtree rooted at a node (KEY-seq) or project (KEY).
  overview           Orient in one project: direction, in flight, next, awaiting, recent sessions, and hygiene.
  artifacts          Read one project's artifact feed: frozen work products, newest first (KEY-aN).
  search             Find any record of one project (task, container, seed, artifact) by id, title, or description.
  seeds              Read one project's grooming queue: live seeds oldest-first (FIFO triage).
  seed               File a seed: an idea, bug, or feature request on a project, to be triaged later. The title is one quoted argument.
  promote            Promote a seed into work: spawn a task from it, or record existing work with --link.
  reject             Reject a seed: it will not be done. The reason is recorded.
  resolve            Resolve a seed: what it asked for is done. The reason is recorded.
  triage             Reconcile a board's seeds: list the untriaged and ready-to-resolve ones, and annotate the tasks whose upstream seed settled. A report, never a gate.
  scratch <command>  Read and keep Scratchpads, the working state of one episode.
  create <command>   Create a project, initiative, phase, or task.
  update             Change a task, phase, or initiative (KEY-seq), or a project (KEY).
  annotate           Append a note to a task, phase, or initiative.
  attach             Attach a document to a project as an artifact, linked to nodes.
  depend             Make a task, phase, or initiative wait on the others named by --on.
  undepend           Stop a task, phase, or initiative waiting on the others named by --on.
  move               Move a task, phase, or initiative under another parent in its project.
  reorder            Change a task's rank among its siblings.
  groom              Mark tasks not_groomed | needs_answers | groomed.
  tag                Add tags to tasks, phases, initiatives, projects, or artifacts.
  untag              Remove tags from tasks, phases, initiatives, projects, or artifacts.

GLOBAL OPTIONS
  -h, --help  Show this help.

Run mimir <command> --help for command details.

mimir doctor · Run read-only diagnostics: local store health, or remote config, credentials, host reachability, version, and token checks. Remote record health is checked with mimir-host doctor. Non-gating: findings exit 0. Prints prose on a terminal and json when piped.

USAGE
  mimir doctor [options]

OPTIONS
  -s, --scope <KEY|all>  Limit local store checks to a project. Defaults to the clone binding; all checks every project. Remote client checks are install-wide.
  -f, --format <format>  Select the output format, records by default. One of: ids, json, jsonl, records, table.

GLOBAL OPTIONS
  -h, --help      Show this help.
      --no-input  Ask no questions, and take every answer from options.  (default: true)

EXAMPLES
  $ mimir doctor
    check the bound project; findings are output, not the status
  $ mimir doctor -s all -f json
    every project, as a findings array
